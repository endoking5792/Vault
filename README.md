# Dental Study Material

Personal study notes compiled from standard dental textbooks (Cohen's Pathways of the Pulp, Ingle's Endodontics, Grossman's Endodontic Practice, Torabinejad's texts, Craig's Restorative Dental Materials, and others), organized into three modules.

- **Module 1 — Conservative & Restorative Dentistry**
- **Module 2 — Endodontics**
- **Module 3 — Dental Materials & Material Science**

Each file is a sub-module of notes with inline citations `[n, p.X]` referencing the source textbook and page, with a full reference list at the end of each file.

Source `.docx` masters are kept locally outside this vault; this repository holds the Markdown versions for version history and for use as an Obsidian vault.
